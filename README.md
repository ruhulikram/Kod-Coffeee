# Kod Coffee — Web App Pemesanan Menu Coffee Shop ☕

Aplikasi Web Mobile-First & Desktop untuk pemesanan menu kopi dan makanan artisanal langsung dari meja coffee shop melalui **Scan QR Code**, terintegrasi dengan simulasi **Payment Gateway (QRIS, E-Wallet, VA)** dan **Portal Admin / Kitchen Barista Board**.

---

## 🌟 Fitur Utama

### 📱 Sisi Pelanggan (Mobile-First 360px–430px & Web View)
1. **Identifikasi Meja Otomatis & QR Code**:
   - Mendeteksi nomor meja via URL parameter (`/t/:token` atau `?table=Table%2004`)
   - Modal simulasi Scan QR dan pemilihan meja (Meja 01–12)
   - Proteksi pesanan agar selalu terikat pada konteks meja yang valid
2. **Katalog Menu & Pencarian Cepat**:
   - Filter kategori (Signature Coffee, Manual Brew, Non-Coffee, Artisanal Bakery & Toast, Hearty Meals)
   - Pencarian instan berdasarkan nama, deskripsi, dan *taste profile*
   - Status ketersediaan menu (Otomatis disabled saat menu *Habis/Sold Out*)
3. **Detail Menu & Customization**:
   - Foto resolusi tinggi kuliner (*generated by AI*)
   - Pilihan catatan cepat (*Less Ice, No Sugar, Oat Milk, Extra Hot*, dll)
   - Stepper jumlah pesanan
4. **Keranjang & Floating Order Bar**:
   - Perhitungan otomatis: Subtotal + Pajak Restoran PB1 (10%) + Biaya Layanan (5%) = Total Bayar
   - Modifikasi jumlah dan catatan item langsung dari drawer
5. **Checkout & Gateway Pembayaran**:
   - Pilihan pembayaran: **QRIS Dinamis**, **GoPay**, **OVO**, **ShopeePay**, **BCA Virtual Account**, **Mandiri Virtual Account**
   - QRIS dinamis yang dapat di-scan secara real-time dengan countdown timer
   - Tombol simulasi pembayaran instan (Webhook callback trigger)
6. **Live Order Tracker (Barista Extraction Pulse)**:
   - Progres timeline real-time: `Paid` ➔ `Confirmed` ➔ `Preparing (Sedang Diseduh)` ➔ `Ready (Siap Di Meja)` ➔ `Completed`
   - Suara notifikasi (Audio Chime) & confetti selebrasi saat pesanan siap
   - Struk digital rincian pesanan dan opsi pesan tambahan

---

### 🖥️ Sisi Staff & Barista (Admin Operations Portal)
1. **Kitchen & Barista Order Board**:
   - Tampilan **Kanban Board** & **Tabel List** interaktif
   - Tombol aksi 1-klik untuk memperbarui status pesanan (*Konfirmasi*, *Mulai Seduh*, *Siap Saji*, *Selesaikan*)
2. **Manajemen Menu & Stok (CRUD)**:
   - Tambah, edit, dan hapus menu
   - Toggle instan ketersediaan stok (*Tersedia* / *Habis*)
3. **Manajemen Kategori**:
   - Tambah, edit, atur urutan, dan aktifkan/nonaktifkan kategori menu
4. **Manajemen Meja & Cetak QR Standee**:
   - Monitoring status okupansi meja (*Kosong*, *Terisi/Dine-In*, *Nonaktif*)
   - Reset dan regenerate QR token unik per meja
   - **Cetak Standee Meja Akrilik**: Desain kartu standee siap cetak (`window.print()`) lengkap dengan branding Kod Coffee dan QR code
5. **Laporan & Analitik Penjualan**:
   - Metrik omset harian, total order, total porsi terjual, dan Average Order Value (AOV)
   - Grafik tren pendapatan 7 hari terakhir
   - Distribusi metode pembayaran
   - Peringkat menu terlaris (Leaderboard)
